KURULUM NOTU

1) Eski çalışan Flask sunucusunu kapat.
2) Bu klasörde sanal ortam aç:
   python -m venv .venv
   .venv\Scripts\activate

3) Gerekli paketleri kur:
   pip install flask qrcode pillow

4) Uygulamayı başlat:
   python app.py

5) Tarayıcıdan aç:
   http://localhost:8000

- /bildirimler
- /dis/menu
- /dis/mutfak
